Firmware file contents
==============================

IBB-sdcard-vXX.YY.img - Disk image file for IBB device SD card. Its to be used in the factory.

IBB-vXX.YY.swu - Software update file for IBB device. To be used for field updates on the web.

XX - Major version number 

YY - Minor version number

Example of XX.YY : 0.54

----------------------------
