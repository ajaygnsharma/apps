This package is designed for use in RX1+1s with serial number beginning with TERX.
It will NOT work with any other RX1+1s.
Upgrading RX1+1s with serial number not beginning with TERX will cause the
RX1+1 to become inoperable and require return to the factory to fix.
Upgrading must use the supplied upgrade utilities ArmSerialDownloader.exe and ArmUdpDownloader.exe.
ArmUdpDownloader.exe is the preferred program for upgrading.
