ZIP file contents
==============================

IBE/IBA/IBR with TE80/TE90 serial number ZIP-23816-0001.zip contains the following

Files:

    1. ReadMeFirst.txt - First read this file
    2. FirmwareUpgradeProcedure.pdf - The process of upgrading firmware is described in this.
    3. ibr_arm_fwVX_YY.bin - The main firmware binary for IBR
    4. ArmSerialDownloader.exe - The Windows utility to upload firmware to IBR via serial port
    5. ArmUdpDownloader.exe - The Windows utility to upload firmware to IBR via Ethernet port over UDPs       
    6. Folder: MIB

       Files:
       
       1. TERRASAT-IBUC-MIB.MIB - The management MIB for IBUC products

       2. TERRASAT-SMI-MIB.MIB  - The Structure of Management Information for the Terrasat enterprise.
       
       3. TERRASAT-TC-MIB.MIB   - The MIB module for textual conventions for the enterprise
