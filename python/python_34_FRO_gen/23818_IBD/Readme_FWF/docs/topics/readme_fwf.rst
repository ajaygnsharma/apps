Firmware File contents
==============================

IBD-sdcard-vXX.YY.img - Disk image file for IBD device SD card. Its to be used in the factory.

IBD-vXX.YY.swu - Software update file for IBD device. To be used for field updates on the web.

XX - Major version number 

YY - Minor version number

Example of XX.YY : 0.05
