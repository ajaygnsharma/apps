Firmware file contents
==============================

RXI-CH-sdcard-vXX.YY.img - Disk image file for RXI-CH device SD card. Its to be used in the factory.

RXI-CH-vXX.YY.swu - Software update file for RXI-CH device. To be used for field updates on the web.

XX - Major version number 

YY - Minor version number

Example of XX.YY : 1.04

----------------------------
