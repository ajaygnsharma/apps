Firmware file contents
==============================

TXI_sdcard_vXX.YY.img - Disk image file for TXI device SD card. Its to be used in the factory.

TXI_vXX_YY.swu - Software update file for TXI device. To be used for field updates on the web.

XX - Major version number 

YY - Minor version number

Example of XX.YY : 1.09

----------------------------
